# Gemini 3 Flash Assistant

Implementasi asisten cerdas menggunakan model **Google Gemini 3 Flash**. Proyek ini mengeksplorasi efisiensi dan kecepatan respon AI dalam menangani instruksi teks kompleks.

## Fitur
- Integrasi Google Gemini API via OpenAI SDK.
- Pemrosesan bahasa alami yang cepat (Flash model).

## Teknologi
- Python 3.12
- Google Gemini 3 Flash
- Python-dotenv

## Cara Instalasi
1. Clone repository ini.
2. Buat file `.env` dan masukkan `API_KEY` serta `GEMINI3_URL`.
3. Install library:
   ```bash
   pip install -r requirements.txt
